# 🌿 웹앱 예시 실습

AI와 지속가능발전(ESD)을 융합한 교육 프로젝트 예시입니다.  
Streamlit을 활용하여 **논문 요약기, 이미지 분리배출 판단기, 멀티미디어 시각화 웹페이지**를 제작할 수 있습니다.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://lecturesnhs.streamlit.app/)

---

## 📌 주요 기능

- 📄 **논문 요약기**: PDF 업로드 → GPT로 요약, 핵심 개념 설명, 탐구 아이디어 제공
- 📸 **이미지 판별기**: 카메라로 찍은 쓰레기 → GPT Vision으로 재활용 여부 분석
- 🗺️ **ESD 캠페인 대시보드**: 지도, 영상, 오디오, 이미지 등 다양한 콘텐츠 통합
- 💬 **Streamlit UI 요소** 적극 활용 (Expander, Tabs, Sidebar 등)
